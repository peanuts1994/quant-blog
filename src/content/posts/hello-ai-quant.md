## 这里会写什么

两个方向，一个交叉点：

1. **AI Agent 工程化**：多智能体编排、上下文工程、端侧推理部署（QNN/MNN/llama.cpp）
2. **量化投资**：A 股策略回测、因子有效性检验、多 Agent 辩论式投研（AI Hedge Fund A 股改造版）

交叉点是最有意思的部分——**把投资大师的决策逻辑建模成 Agent，让它们互相辩论，再用真实 A 股数据回测**。这套东西能不能跑赢指数？我不知道，但把过程公开记录本身就是最好的学习方式。

## 内容来源

所有文章基于真实项目产出：跑通的回测、实测的延迟数据、踩过的坑。不写二手翻译文。

- 数据层：腾讯/东财直连行情（不依赖付费终端）
- 推理层：GLM / DeepSeek 云端 API + 本地 4060 端侧部署
- 回测层：自研 Python 框架 + JoinQuant 策略移植
